- اپلیکیشن‌های مارکت‌پلیس آگهی فارسی (مشابه دیوار / شیپور)

# پرسوناها (اجباری — همه را در طراحی در نظر بگیر)

## ۱) خریدار / دنبال‌کننده آگهی
- هدف: پیدا کردن سریع کالا/خدمت مناسب
- Needs UI: جستجوی قوی، فیلتر کاربردی، اعتبار فروشنده، تصاویر و توضیحات کامل
- Pain: آگهی نامرتبط، ترس از کلاهبرداری، مقایسه سخت، اطلاعات ناقص، آگهی قدیمی
- Journey: ورود → جستجو/دسته → فیلتر → لیست → جزئیات → چت/تماس → (نظر)

## ۲) فروشنده شخصی (Individual Seller)
- هدف: فروش سریع کالا / ثبت سریع آگهی
- Needs UI: فرم مرحله‌ای ساده، پیشنهاد دسته خودکار، راهنمای نوشتن عنوان/توضیح، ویرایش و تمدید آسان
- Pain: ثبت طولانی، انتخاب دسته سخت، نوشتن متن سخت، دیده‌نشدن آگهی
- Journey: ورود سریع با موبایل → ثبت آگهی → دسته → اطلاعات+عکس → قیمت+موقعیت → انتشار → مدیریت → پیام

## ۳) فروشنده کسب‌وکار (Business Seller)
- هدف: جذب مشتری، مدیریت چند آگهی، آمار
- Needs UI: داشبورد، گزارش بازدید/تعامل، مدیریت گروهی، تبلیغات
- Pain: نبود آمار، مدیریت سخت، هزینه تبلیغات نامشخص
- Journey: ثبت‌نام سازمانی → ایجاد آگهی(ها) → مدیریت → تبلیغ ویژه → پاسخ مشتری → تحلیل عملکرد

## ۴) متقاضی / ارائه‌دهنده (نقش‌های تکمیلی از research)
- متقاضی: ثبت نیاز و دریافت پاسخ
- ارائه‌دهنده: پیدا کردن فرصت و ارائه پیشنهاد
- در MVP اولویت پایین‌تر از ۳ پرسونای بالاست؛ فقط در IA جا باز بگذار مگر خلافش گفته شود

# User Flows اجباری برای Prototype فیگما

## Flow A — خریدار: پیدا کردن محصول
ورود اپ → خانه → جستجو یا دسته → فیلتر → لیست → جزئیات → چت یا تماس

## Flow B — فروشنده شخصی: ثبت آگهی
ورود/OTP → خانه → ثبت آگهی → انتخاب دسته → عکس → عنوان/توضیح → قیمت/موقعیت → پیش‌نمایش → انتشار → آگهی‌های من

## Flow C — کسب‌وکار: مدیریت
ورود پنل کسب‌وکار → داشبورد → ایجاد/مدیریت آگهی → آمار → تبلیغ ویژه → پاسخ پیام‌ها

## Flow D — ذخیره و بازگشت
جزئیات آگهی → افزودن به علاقه‌مندی‌ها → علاقه‌مندی‌ها → بازگشت به جزئیات

# قوانین کیفیت
1. هیچ صفحه‌ای از لیست ضروری جا نماند
2. منطق از همین Research؛ ظاهر Premium Minimal و متمایز از دیوار/شیپور (شلوغ نباشد)
3. اعداد دقیق بنویس (16px نه «کمی فاصله»)
4. UI copy فارسی واقعی بنویس، نه لورم‌ایپسوم
5. اگر چیزی در research نبود با برچسب `[فرض]` مشخص کن
6. اگر خروجی طولانی شد بعد از Tokens + Inventory + Components توقف کن و بپرس از کدام صفحه Screen Spec را ادامه بدهم؛ ولی A–D باید در پاسخ اول کامل باشد
7. حس برند «سرعت + سادگی + اعتماد + پریمیوم» در همه صفحات حفظ شود
