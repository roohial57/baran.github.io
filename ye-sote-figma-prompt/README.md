# اپ یه سوته ← تبدیل به فیگما با ChatGPT

این پوشه یک **پرامپت جامع و آماده کپی** دارد تا صفحات اپ «یه سوته» را از روی وایرفریم، مستند UX، HTML و تصویر مرجع، به مشخصات کامل ساخت در Figma تبدیل کنید.

## فایل اصلی

- [`PROMPT-FOR-CHATGPT.md`](./PROMPT-FOR-CHATGPT.md) — پرامپت کامل + راهنمای استفاده

## فایل‌هایی که باید به ChatGPT ضمیمه کنید

1. `ye-sote-wireframes (1).html`
2. `اطلاعات پیش تولید ui and uxیه سوته.xlsx`
3. `ye-sote.html`
4. `1785154688119_{9404450D-B09F-4CEC-A7A7-3321E48A6D42}.png`

## سه قدم سریع

1. بخش بین `--- شروع پرامپت ---` و `--- پایان پرامپت ---` را کپی کنید
2. در ChatGPT پیست کنید و هر ۴ فایل را Attach کنید
3. خروجی را مرحله‌به‌مرحله در Figma پیاده کنید (یا پرامپت‌های Figma Make را مستقیم استفاده کنید)

## خروجی‌ای که از ChatGPT می‌گیرید

- Design Tokens (رنگ، تایپ، فاصله)
- لیست کامل صفحات
- مشخصات صفحه به صفحه
- کامپوننت‌ها و واریانت‌ها
- نقشه Prototype
- پرامپت آماده برای Figma Make
- HTML/Tailwind برای ایمپورت با html.to.design
