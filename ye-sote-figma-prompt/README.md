# اپ یه سوته ← پرامپت فیگما (نسخه ۲ — بر اساس اکسل واقعی)

پرامپت جامع ChatGPT برای تبدیل اپ آگهی «یه سوته» به صفحات Figma، غنی‌شده با داده‌های فایل:

`اطلاعات پیش تولید ui and uxیه سوته.xlsx`

## فایل‌ها

| فایل | توضیح |
|------|--------|
| `COPY-PASTE-PROMPT.txt` | فقط متن پرامپت — مستقیم کپی در ChatGPT |
| `PROMPT-FOR-CHATGPT.md` | پرامپت + راهنما |
| `RESEARCH-SUMMARY.md` | خلاصه استخراج‌شده از اکسل |
| `README.md` | همین فایل |

## سه قدم

1. `COPY-PASTE-PROMPT.txt` را کامل کپی کنید
2. در ChatGPT پیست کنید (اگر HTML وایرفریم / ye-sote.html / PNG دارید ضمیمه کنید)
3. خروجی A–D را بگیرید، بعد صفحه به صفحه Screen Spec و پرامپت Figma Make را اجرا کنید

## نکته
این نسخه حتی بدون فایل HTML هم کار می‌کند، چون Inventory، Flows، Personas و Brand از اکسل داخل پرامپت آمده‌اند.
