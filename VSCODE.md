# VS Code — بدون npm و بدون خطا

## کارهایی که باید بکنی

1. این ZIP را دانلود و Extract کن:  
   https://github.com/roohial57/baran.github.io/archive/refs/heads/main.zip

2. VS Code → **File → Open Folder** → همان پوشه Extract شده

3. اگر پیشنهاد نصب **Live Server** آمد → Install

4. فایل `index.html` را باز کن → راست‌کلیک → **Open with Live Server**

یا از منو: **Terminal → Run Task… → Open Portfolio (no npm)**

یا `F5` → **Open Portfolio in Chrome**

## مهم

- لازم نیست `npm install` یا `npm run dev` بزنی
- فایل اصلی: `index.html` (همه CSS داخلش است)
- پوشه `src/` مال سورس Astro است؛ اگر Node نداری بازش نکن
