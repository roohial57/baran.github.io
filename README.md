# Roohallah Alizadeh — Developer Portfolio

Personal portfolio site built with the [DevPortfolio](https://github.com/RyanFitzgerald/devportfolio) Astro template.

**Live:** [baran288.ir](https://baran288.ir)

## Customize

Edit `src/config.ts` for name, about text, skills, projects, and experience.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

GitHub Actions deploys `dist/` to GitHub Pages on every push to `main`.
