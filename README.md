**https://roohial57.github.io/**

## Publish to GitHub profile

```bash
git clone https://github.com/roohial57/baran.github.io.git
cd baran.github.io
npm install
npm run publish:profile
```

Then set Website on your GitHub profile to `https://roohial57.github.io/`

## Local

```bash
npm install
npm run dev
```
